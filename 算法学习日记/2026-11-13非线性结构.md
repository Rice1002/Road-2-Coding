# **非线性结构**
今天做了两个作业题,是树和图的相关题目.这两部分是数据结构里面核心的结构,也是比较难理解的部分.因为它并不像线性结构(数组,队列,栈,链表)那么是一个一维的结构,他是一个复杂的结构.  

## 第一道题:二叉树的前序建树与遍历


* **题目核心**:输入一个带空格的字符串（空格代表空子树），按前序顺序建立一棵二叉树，然后分别输出它的前序、中序和后序遍历。
* **核心知识**:
    * **递归**:树的结构天然的就适合用递归的方式来进行处理.建树以及三种遍历方式(先序,中序,后序)本质上都是递归.  
    我们在写递归函数时一定要注意明确终止条件,如果函数没有出口,那么就会一直递归下去直到爆栈.
    >一棵树要么是空树，要么是一个根结点加上左子树和右子树；而左子树、右子树又都是树。  这种 `“整体由同类的小整体组成”` 的结构叫自相似结构，天然对应递归。
    * **引用**:这是这道题最大的难点(也是我纠结了一下的问题)。因为我们不仅要修改指针指向的内容，还要修改指针本身（让它指向新分配的内存），所以必须传引用。如果不加 &，函数内 new 出来的内存只是局部变量，主函数里的根节点依然是 nullptr。
    >这里不使用引用使用指针的指针也是同样的效果,但是指针的引用更加安全,可读性也更好.
    * **遍历建树**:本题要求的是前序建树,但其实每种顺序的实际递归相差不大,只是读取顺序的问题.但是前序建树是最合理的一种.
```

#include <iostream>
using namespace std;

struct BiTNode {
    char data;
    BiTNode *lchild, *rchild;
    // 构造函数，方便 new 的时候初始化
    BiTNode(char d) : data(d), lchild(nullptr), rchild(nullptr) {}
};
typedef BiTNode* BiTree;

// 1. 前序建树
void CreateBiTree(BiTree &T) {
    char ch;
    if (!(cin >> ch) || ch == ' ') { // 处理空格和EOF
        T = nullptr;
        return;
    }
    T = new BiTNode(ch);
    CreateBiTree(T->lchild);
    CreateBiTree(T->rchild);
}

// 2. 先序 (根->左->右)
void PreOrder(BiTree T) {
    if (!T) return;
    cout << T->data << " ";
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

// 3. 中序 (左->根->右)
void InOrder(BiTree T) {
    if (!T) return;
    InOrder(T->lchild);
    cout << T->data << " ";
    InOrder(T->rchild);
}

// 4. 后序 (左->右->根)
void PostOrder(BiTree T) {
    if (!T) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    cout << T->data << " ";
}

// 5. 释放内存 (以防内存泄漏)
void DestroyTree(BiTree &T) {
    if (!T) return;
    DestroyTree(T->lchild);
    DestroyTree(T->rchild);
    delete T;
    T = nullptr;
}

```
